# Agent instructions

## Public changelog (PRs to `main`)

User-facing changes that will land on **`main`** must update `app/changelog/releases.ts` (plain language, no internals).

A GitHub Action posts a sticky reminder on PRs to `main` if that path was not touched. If you see it — or you are opening/updating such a PR — update the changelog yourself in the background and mention it in your summary. Docs/chore-only PRs can skip with a note in the PR template checkbox.

Live page: `/changelog`
