## What it is

DegreeIntelligence (DI) turns your Yale transcript into a live picture of where you stand and where you're headed. Upload your unofficial transcript and DI parses it, maps your courses to major and distributional requirements, and keeps the whole thing up to date as you plan ahead.

## Features

- **My Major** — track progress toward one or more majors, with shared-course conflict management for double majors.
- **Simulator** — plan future semesters, save multiple plans, set a default, and watch requirement progress update in real time.
- **Distributionals** — visualize your skills and disciplinary distributional requirements at a glance.
- **Academic Stats** — charts for credits, GPA, and credit distribution across your time at Yale.
- **Friends** — compare progress with friends.
- **Dan** — an AI advisor for degree questions.
- Light and dark mode throughout.

## Tech

Next.js (App Router) · React · TypeScript · Tailwind CSS · Framer Motion · Firebase · MUI X Charts · Chart.js

## Running locally

```bash
yarn install
yarn dev
```

Then open [localhost:3000](http://localhost:3000). You'll need a `.env.local` with the relevant Firebase and AI provider keys.
